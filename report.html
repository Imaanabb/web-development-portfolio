Reflection of module experience

In this section i will reflect on my experience of learning web development, this will include the positive alongside, the challenges i had faced throughout this assignment.

How did I find the module?

The web development module has been an exciting experience. In this module i learnt how to build a website using HTML and CSS, I found this module enjoyable and engaging as it gave me a real insight into how much work goes into building a website. The assignment did not feel like typical assignment work, instead it was a fun and rewarding experience for me. It was rewarding to see my ideas on a fully functioning website. Although, i enjoyed the process, I did find certain aspects of the assignment challenging. Structuring the website correctly was difficult initially. This was due to having difficulty in understanding how different elements work together to create a clear and organised layout. To help with these challenges, i used AI as an assistive tool to support my learning and develop a better understanding of how to approach these challenges. I also found it challenging to position the elements correctly on the page ensuring everything appeared exactly where i wanted it. Additionally, another challenge was making the website fully responsive for mobile devices was difficult. As i attempted to approach this with seperate CSS files however, this made the process much complicated and led to confusion. Therfore, i used media within a single CSS file, and used AI to assist me in understanding media queries and how to implement responsive designs efficiently. Another challenge i had come across was resolving validation errors within my html codes. These issues included missing colons, unclosed tags, incorrect structure and layout. However, through debugging and, correcting these validation errors, i had started to gain a better understanding of the structure this language wants followed. Overall, despite the challenges, the assignment was very engaging and, rewarding. It was great to see the final outcome of a website that i had built.

Design decisions

For my design decisions, i researched modern portfolio websites as i wanted my website to have a clean, modern aesthetic. I explored different layouts and styles, such as minimal layouts and, dark themes. During my research, i came across a portfolio that had inspired my design.
